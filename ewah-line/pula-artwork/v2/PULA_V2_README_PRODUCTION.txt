WHAT CHANGED FROM v1, AND WHY
-----------------------------
1. ALL TYPE IS NOW OUTLINED PATHS. v1 set every word as live <text> calling Arial.
   A printer without Arial silently substitutes a different font and the lockup
   changes shape. v2 contains zero live text in any separation file.
   Typeface: Liberation Sans Bold, SIL Open Font Licence — commercial use and
   embedding permitted, no Monotype licensing question.

2. THE RAIN WAS REBUILT. v1 placed 15 threads on a perfectly regular 20-unit grid,
   all unbroken, all identical spacing. That reads as a comb. Tech pack v1 requires
   "asymmetric clusters, varied length and spacing". v2 uses the 75-thread system:
   three asymmetric clusters, varied length, varied weight, some threads broken
   mid-fall, 7 isolated on the reflective layer.

3. THE PUFF ELEMENT IS ON ITS OWN FILE. v1 had PULA, the rule and A ene!! together.

4. STROKES ARE EXPANDED TO FILLED PATHS. No stroke-width dependency at the RIP.

5. HERO BACK WAS RE-LAID OUT. In v1 the rain ran through the anthem line. Type is
   now left-aligned at x=140 with an enforced 84-unit gutter before the rain.

SEPARATION COLOUR CONVENTION — READ THIS
----------------------------------------
Every separation file is BLACK ON TRANSPARENT. Black marks where ink goes. It is
NOT the ink colour. Ink colours are named per file below and must be matched to
physical Pantone references, not to screen hex values.

STILL OUTSTANDING — DO NOT BURN SCREENS UNTIL THESE CLEAR
---------------------------------------------------------
A. "A ene!!" IS NOT DRAWN. It is specified as hand-lettered or script. File 10
   marks its position and size only. It must be hand-lettered, or set in a
   properly licensed script face and outlined, before production.

B. THE COORDINATES ARE UNVERIFIED. 22.3285 S, 24.6849 E is approximately the
   geographic centre of Botswana. Confirm it is the intended location before any
   screen is burned. This has been an open hold since 8 September.

C. TYPEFACE IS A WORKHORSE, NOT A DISPLAY FACE. Liberation Sans Bold is clean and
   evenly weighted, which suits 3D puff, but it is not a distinctive letterform.
   A designer should decide whether the hero lockup deserves a licensed display
   face. If it changes, only files 01, 03 and 07 need rebuilding.

D. INK MATCHING IS PHYSICAL. Navy 0E2745 and Botswana blue 58A9E1 in the composite
   files are screen references. Match to approved Pantone chips on the actual
   garment fabric.

E. ASK THE PRINTER FOR A SEPARATION AND PLACEMENT PROOF BEFORE SAMPLE PRODUCTION.
