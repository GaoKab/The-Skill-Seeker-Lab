# PULA — Fast Track to a Sample in 5 Days

Goal: a real printed tee in hand within 5 days, and a viable BOIPUSO 60 drop for 30 September.

## Why the mockups can't go straight to a screen printer (plainly)

Not a rule — plumbing. Three real reasons:

1. **Screens are per-colour.** Screen printing burns one screen per ink. The printer needs the art already split: PULA lettering, rain threads, the puff layer, the reflective layer, fine text. A flat image of a whole shirt can't be split apart.
2. **Resolution.** Inside a mockup image of a whole garment, the actual chest print is only a few hundred pixels across. Print needs a few thousand across at final size.
3. **AI artifacts.** Mockup lettering carries small distortions that vanish at thumbnail size and are obvious printed 12 inches wide. Tech pack v1 flags this itself — and this collection carries the national anthem line, so a warped letter is not survivable.

**But rebuilding it is small.** A word, a script phrase, thin lines, small text, a droplet. Hours, not weeks — $50–150 with a freelancer, or an afternoon for any designer with Illustrator.

## The 5-day plan

| Day | Action |
|---|---|
| **1 (today)** | Commission the vector rebuild. Send the designer brief below + tech pack v1 + the boards + `pula-artwork/rain-line-system-v1.svg` (the rain system is already done — see below). Ask for 24–48h turnaround, paid rush is fine at this price |
| **1 (parallel)** | Email 2–3 **local** printers with the sample request below. Ask specifically for **DTF or DTG** for the sample — no screens, no setup fee, 1–2 day turnaround |
| **2–3** | Vectors back → review letterforms at full size → send print-ready file to the printer |
| **4–5** | **Sample tee in hand.** Wear it, photograph it, check the letterform weight and how the rain reads at arm's length |
| Then | If approved: screens burned for the production run with puff + reflective, ordered same week for 30 Sept |

**Two-track print rule:** DTF/DTG gets a sample on your body this week. Screen printing with puff and reflective is the production method. Don't confuse the sample's finish with the final one.

## Head start: the rain-line system is already vectorised

`pula-artwork/rain-line-system-v1.svg` — 75 thin threads, generated to tech pack v1 rules (thin, thread-like, mostly vertical, asymmetric clusters, varied length and spacing, one-sided shoulder-led, generous negative space on the type side, a few threads broken mid-fall). Artboard is 305 × 406 mm = the standard 12 × 16 in tee print area.

It ships **pre-separated into layers**:
- `RAIN_MAIN` — standard ink threads
- `RAIN_REFLECTIVE` — only 7 threads, per the "selective reflective" rule
- `TYPE_PLACEHOLDER` — a guide box showing where the PULA lockup sits. **Not for printing.**

Opens in Illustrator, Affinity, Inkscape, or Figma. Colours are placeholders — match the blue to the approved Botswana Pantone before output.

## What to check the moment the sample arrives

Letterform weight at arm's length · does the rain read as rain or as scratches · puff height (production only) · whether the anthem line is spelled and spaced perfectly · print hand after one wash · blank colour against the ink

## Honest gate

If vectors are not commissioned within roughly 3 days, 30 September stops being real for screen-printed tees. The fallback is still good: **DTF production** can run much later and still deliver, it simply won't have the puff and reflective finish. Decide which matters more — the date, or the finish — and say it out loud rather than discovering it on the 28th.
