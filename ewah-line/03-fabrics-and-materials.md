# EWAH Fabrics & Materials

The boards promise: **4-way stretch · moisture-wicking · breathable · squat-proof · lightweight (summer)**. This maps to five fabric platforms. Locking these early keeps the whole line consistent and simplifies sourcing.

## Fabric platforms

| Code | Platform | Composition (target) | Weight | Used in |
|---|---|---|---|---|
| **A** | Sculpt compression knit | 73–78% recycled polyamide (nylon) / 22–27% elastane, warp-knit or circular interlock, matte "buttery" hand | 220–240 gsm (core) / 180–200 gsm (summer "A light") | Tunic dresses, Curve Legging, bodices, Shield Dress |
| **B** | Pleat-holding knit | 90–100% polyester (elastane ≤10%), warp knit — polyester is required for permanent heat-set pleats | 160–190 gsm | All pleated skirts/panels, Pleated T-Shirt Dress panels |
| **C** | Flow/tier lightweight knit | Poly-elastane single jersey or crepe knit with drape | 140–170 gsm | Skirt tiers, Dresskort, summer layers |
| **D** | Matte drape jersey | Modal-poly-elastane or heavy matte poly jersey | 200–230 gsm | Warrior Flow rust pieces (wrap tunic, split dress) |
| **E** | Flow pant stretch woven | Poly or nylon 4-way stretch woven / heavy crepe knit | 180–210 gsm | Flow Pants, harem silhouettes |
| **T** | Ease tee jersey | 100% combed cotton or 50/50 cotton-modal, heavyweight | 220–250 gsm | Oversized + Pleated T-Shirt Dress bodies |

### Non-negotiable performance tests (request lab results or test the sample yourself)
1. **Squat-proof:** full squat under bright light in every colorway — no sheer, no seam gape
2. **Wicking + dry time:** sweat patch dries without dark clinging (especially Onyx vs. Bone)
3. **Pleat retention:** pleats survive 5 home washes (this kills cheap pleated fabric — insist on heat-set poly)
4. **Recovery:** waistband and knee recover after 30 wears — elastane % and quality matter more than gsm
5. **Pilling:** Martindale ≥ 20,000 rubs for knit A

## Trims & components

| Item | Spec |
|---|---|
| Zippers | YKK or SBS #3 coil, gold/antique-gold pull, autolock, zip garage |
| Elastic | 32–38 mm plush-back waistband elastic for shorts liners; clear elastic for stabilizing shoulder seams |
| Thread | Poly-core stretch thread; textured poly (wooly nylon) in loopers for soft interior seams |
| Branding | Gold matte heat transfers (test wash durability) + gold-thread embroidery for heavy knits |
| Labels | Woven damask main label, printed satin care label, recycled-card hang tags with capsule name + "Sculpted, not exposed." |

## Color standards

Build a physical color card early — dye lots drift, and Onyx/Aubergine/Rust must match across fabric platforms A/B/C/D in the same garment (e.g., Warrior Flow Dress body vs. pleats).

| Color | Pantone reference (starting point) |
|---|---|
| Onyx | PANTONE Black 6 C |
| Bone | PANTONE 9224 C |
| Clay | PANTONE 4755 C |
| Rust | PANTONE 7592 C |
| Aubergine | PANTONE 5185 C |
| Olive | PANTONE 5747 C |
| Gold (branding) | PANTONE 872 C (metallic) / 4515 C (matte print) |

Order **lab dips** (dyed fabric swatches) for approval before bulk — approve them in daylight, not indoor light.

## Sourcing routes

| Route | Good for | Notes |
|---|---|---|
| Full-package activewear factories (China — Guangdong/Fujian; or Turkey, Portugal) | Fastest path: they source fabric A/B/C in-house, MOQ 100–300 pcs/style/color | Ask specifically for "yoga dress / tennis dress with built-in shorts" experience and pleating capability in-house |
| Fabric mills direct (e.g., recycled nylon-elastane suppliers) + CMT factory | More control, better margins at scale | Only after Phase 1 proves the line |
| African manufacturing (Ghana, Kenya, Morocco, Mauritius, South Africa) | Brand-story alignment, AGOA/duty advantages, shorter route to African market | Mauritius + Morocco have strong knit performance-wear capability; vet pleating capacity carefully |

**Practical Phase-1 recommendation:** one full-package factory that can handle knit A + pleating B under one roof. Split sourcing across factories only after the fit blocks are locked.
